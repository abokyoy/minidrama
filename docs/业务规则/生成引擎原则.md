# 生成引擎原则（业务级）

> 领域：视频生成引擎（ComfyUI / API）的运行约束。属业务原则，项目级、非用户级、非开发规则。

---

## 1. 长任务特殊坑（本项目实测）

| 现象 | 实情 | 业务规则 |
|------|------|---------|
| 生成为啥慢 | 真瓶颈是**系统内存满** → 走页文件 → 采样速度掉 2.5 倍 | 生成前必须清场杀占内存进程（如 `gh.exe`）释放内存 |
| 一次完整生成 | **13–15 分钟**（模型加载最慢，8 步采样） | 长任务必须后台跑 + 进度回报，不阻塞 |
| 每满 3 段 | 必须 kill + 重启 ComfyUI，避免越接越黑 | 调度器自动每 3 段断链重启 |
| 两实例同时跑 | ⛔ 抢显存会崩 | ⛔ 禁止并行实例；队列串行提交 |
| ComfyUI 重启权 | **只属于生成器**。人手动 start 会清空队列导致 driver 死等 | 重启只能由生成器调度触发 |

---

## 2. 黑窗口 → 进度可见（原用户硬性要求，GUI 化后等价落实）

> 用户原话（2026-10-10）：「必须让用户看到黑窗口 能看到进度」。

- 原要求：ComfyUI 用可见黑窗口启动，用户实时看采样进度。
- **本系统（Electron 本地工具）落实方式**：不再依赖外部黑窗口，改为**应用内进度视图**——进度条 + ComfyUI 实时日志流，等价满足「用户实时看得到生成进度」。
- ⛔ 静默后台生成、用户看不到进度 = 违反本条。任何生成任务必须在 UI 上暴露实时进度与日志。

---

## 3. 调用方式：API 生成 或 本地 ComfyUI（二选一）

系统支持两种生成来源，由用户在生成面板选择：

| 方式 | 说明 | 业务约束 |
|------|------|---------|
| **本地 ComfyUI** | 调用本机 ComfyUI 实例（官方 H3 端口 **8189**，旧实例 8188） | 实例启停由生成器调度；输出 `D:\output_h3off` / `D:\output` |
| **API 生成** | 调用远程生成 API（如 MiniMax H3 API） | 走 V2RAYN 代理（见 `网络与环境原则.md`）；密钥用环境变量/加密配置，不落明文 |

- 续写链：奇数开头段 fixed，之后连续两段 chain 接上一段，每 3 段断链重启（详见 `docs/原则/系统架构梳理.md` 生成流程）。

---

## 4. 续写链工作流

- 节奏：seg01 fixed → seg02/03 chain ← 上一段 → 断链重启 → seg04 fixed → seg05/06 chain → 断链…
- ⛔ chain 第 1 段绝对不能用（节点写死他人路径 → `prev=None` 必退回 fixed）。
- ⛔ 参考图数量须与已认可段逐字一致，否则人物复制。
- ⛔ **禁正则批量改写镜头段**（截断句子 → 相邻两刀重绘同脸越推越虚），改镜头须精确改每一刀 + 抽帧人眼核对。
