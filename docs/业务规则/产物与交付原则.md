# 产物与交付原则（业务级）

> 领域：生成产物的交付与质量验证。属业务原则，项目级、非用户级、非开发规则。

---

## 1. 产物清单必须给出（交付硬要求）

每有新产物出来，**必须给一张清单表**：

| 字段 | 说明 |
|------|------|
| 产出时间 | 生成完成时间 |
| 文件名 | 产物文件名 |
| 大小 | 文件体积 |
| 时长 / 页数 | 视频时长或文档页数 |
| **完整绝对路径** | 真实落盘路径（见 §3） |

并说明：这一份**好在哪、还差什么**。⛔ 不许含糊说「已完成」。

---

## 2. 工具会骗人（质量验证铁律，本项目实测）

生成工具/校验器并不可全信，必须交叉验证：

1. **校验器本身也会骗人**：上线前必须造已知答案样本先验证它自己（改完校验脚本必跑自检样本）。
2. **中间产物固定名须每次重算**：固定名 + 已存在就跳过 → 读到上一支片；⛔ 绝不 `if not exists: skip`。
3. **抽帧拼图人眼核对**：人物复制检测器（YuNet）抓不到侧脸/背身 → 必须抽帧拼图**人眼看**，不能只看审计器绿灯。
4. **花屏查码率**：均值合格也可能是花屏 → 查**码率**（正常 4.0M / 花屏 10.4M）。
5. **模型完整性**：尺寸自洽不够，必须做内容探针。
6. ⛔ 换参考图画面没变 → 下游读的是自己目录里的旧图 → 文件名带 md5 + 定位到目标实例自己的 input/。

**→ 中间产物落固定路径的工具必须每次重算；校验器上线前必须先验证校验器自己。**

---

## 3. 真实路径核对（日志不可信）

⛔ **日志里打印的路径可能和实际落盘位置不一致**（曾一直报 `D:\output\`，实际在 `D:\output_h3off\`；序号也报 1 实际是 13）。

- 一律用 `ls -lat` 按修改时间核对**真实落盘位置**再报给用户。
- 抽帧核对 `"$PY" _dup_check.py <mp4> 8`（每 8 帧 ≈ 0.33 秒）；⛔ 抽帧拼图缩小后会把文件柜里的文件夹误判成墙上图表 → 看单帧原图再下结论。

---

## 4. 常用校验动作（交付前必做）

| 何时 | 做什么 |
|---|---|
| 改完提示词 | 跑提示词审计（24 项：官方规范 + 七条铁律） |
| 改完 beats | 跑节拍自检（时间窗/说话人/禁用词/台词引号/致暗词/烧字幕） |
| 出片后 | 抽帧拼图人眼看人物复制 + 全黑/花屏体检 + 码率核对 |
| 改完剧本 | 对照定版台账，确认改动已登记 |
