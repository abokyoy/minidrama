# 创作方法论原则（业务级 · 短剧内容方法论）

> 领域：短剧**内容本身**的创作方法论。属业务原则（业务规则的一种），项目级、非用户级、非开发规则。
> **权威细节在 skill `short-drama-creation`**（十阶段流水线 + 七条铁律 + 模板库 + 校验脚本）。
> 本文件只列「业务必须遵守的硬约束」，不重复方法论细节。

---

## 1. 十阶段流水线（不许跳步）

```
零 市场调研（番茄/红果榜单）→ 一 立项 → 二 设定 →★投票门A→ 三 契约 → 四 评审门
    → 五 文字剧本 → ★投票门B → 六 连续脚本 → 七 分镜提示词 → 八 成片体检
```

- 每一阶段有门禁，门禁不过不许进下一阶段。
- ⛔ 顺序绝对不可倒（最常见的死法：先写分镜回头补剧本 → 镜头空间关系跳变）。
- ⛔ **禁止只写对话不写表演**；⛔ **禁止镜头之间人物空间关系跳变**。

### 两条门禁不能互相替代
| 门 | 判什么 | 局限 |
|---|---|---|
| 投票门（JEV） | 观众喜不喜欢 | 判不了故事讲不讲得通 |
| 评审门（五维+三毒素） | 结构对不对 | 判不了观众想不想看 |

---

## 2. 七条铁律（写作时就必须遵守）

1. **空间连续性**：每镜写明人物相对道具/墙/对方的方位，且与上镜结尾一致（抄上镜站位原文逐字对照）。
2. **代价式战果**：每次赢都要当场看见代价，零成本取胜 = 爽点作废。
3. **对手不降智**：反派每 10 集必须有一次有效进攻（增火力/造成实际损失）。
4. **不做闭门创作**：立项前必看番茄首秀榜 + 红果真人榜 + 红果 AI 漫剧榜，留抓取日期。
5. **客群投票不取平均**：任一分群留看率 ≥90% 才过门（四分群：县镇中年男/一二线新市民/都市职场中坚/小镇职场女）。
6. **爽点先挑卡**：写每集前去 `references/模式库.md` 挑一张卡，不许临场想；同招式家族 ≥3 次必须换招。
7. **反派降智=信息差**：角色卡填已知/未知/认知边界；信息差不能靠隐藏身份（底牌必须前 3 集亮）。

---

## 3. 提示词三附律（扩散模型特性）

- **否定句铁律**：扩散模型无否定能力、只做软匹配。排除一个东西 = 正面描述你要什么 + 彻底不提那个词。对称/占比措辞（`each one holding her half`/`left/right/centre`）是隐式数量指令。
- **参考图铁律**：送模型的参考图必须单人正面全身（设计图常同一人出现 4 次 → 裁单张）。排查人物复制：①图里有几人②画面有无对应图③几张环境图④有无否定句。
- **超长提示词铁律**：正文只写 **350–500 英文词**；超长 = 动作稀释 = 全糊。10 秒打斗片 3 刀不是 5 刀。

---

## 4. 定版存档铁律

- `终版剧本/X00N_终版.md` 只存**经用户口头确认定版**的内容；未确认稿一律不写入。
- 每次写入在文件顶部「定版台账」登记：日期 / 内容 / 用户确认原话。
- ⛔ 作废的设定必须显式写「原 XX 口径作废」，不能悄悄删（后续 Agent 会读旧稿）。

---

## 5. 核心风格锚点

- 高级电影质感、有镜头感、电影滤镜调色；人物俊美；光影通透**不要太暗**。
- **9:16 竖屏**（纵深前后排，禁止一排人横向铺开）；**不烧字幕**（后期统一加）；人物胸前**不许有文字**（H3 画中文必变形）。
