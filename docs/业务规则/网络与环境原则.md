# 网络与环境原则（业务级）

> 领域：本机网络走向与代理环境。属业务原则，项目级、非用户级、非开发规则。

---

## 1. V2RAYN 死代理环境变量（本机特例，必踩）

⚠️ 环境变量里的 `HTTP_PROXY` / `HTTPS_PROXY` 常指向 WorkBuddy 内部服务，**对外一律 502**（看起来像目标站点被封，实际只是代理选错）。

**业务规则（所有下载/外网脚本必须遵守）**：
1. 脚本开头先 pop 掉 `HTTP_PROXY` / `HTTPS_PROXY` / `http_proxy` / `https_proxy` / `ALL_PROXY` / `all_proxy`。
2. 再硬编码 `http://127.0.0.1:10808`（V2RAYN 真实代理）。
3. 实测：同一 URL 手写 10808 探测 6/6 成功，脚本跑起来走死代理 502。

---

## 2. 网络走向规则

| 目标 | 走向 | 说明 |
|------|------|------|
| 外网（huggingface / pypi / github api / stitch / 生成 API） | **必须走代理** `127.0.0.1:10808` | 命令行临时设 `HTTP_PROXY`/`HTTPS_PROXY` |
| localhost / 127.0.0.1（ComfyUI 8188/8189、生成本地 DB） | **不代理** | 设 `NO_PROXY=localhost,127.0.0.1`，否则本地接口反而不通 |
| 局域网设备 | 不代理 | 直连 |

- Git 有独立代理配置，环境变量不影响 Git，Git 需单独 `-c http.proxy=...`。
- 代理不通 → 先确认 V2RAYN 客户端是否在运行 → 未运行则重启 V2RAYN（提醒用户或经授权后由 Agent 执行）。
