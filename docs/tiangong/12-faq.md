# 12 · 常见问题与术语表
 新手最常问的 12 个问题，以及天宫专有名词速查（骨架、模式卡、lorebook、写前约束、守护灯…）。


这一篇讲什么：遇到问题时查这里——最常见的问题 + 天宫术语表。
前置条件：无，随时可查。


## 一、新手最常问的 12 个问题


### Q1：40 维骨架会不会太多，填不完？

不会。新手只需先填 核心冲突、主角卡、金手指 三个维度就能开始写，其余在写作过程中由系统自动抽取回填。骨架是活的，不是一次性考试。


### Q2：我不会配 API Key，能用吗？

能。选「AI IDE 文件交换」通道：导出任务卡 → 粘进你熟悉的 AI IDE → 回贴导入。零配置、零成本、数据不出本机。详见 11 篇。


### Q3：AI 写出来的有”AI 味”怎么办？

内置三层去 AI 味检测（词表 + 句式 + 可选模型），写完自动跑。高危句可「一键改写」，命中词还会进”文风避雷库”，下次写作自动规避——越写越像你。


### Q4：我的稿件会上传到云端吗？

不会。本地化运行，稿件与提示词全部存在本机 IndexedDB，不上传云端。只有你主动开启”自动云备份”时，备份文件才会上传到你自己的 COS/OSS。


### Q5：写一本 300 万字，AI 要花多少钱？

用 DeepSeek 全链路约 ¥20；用 AI IDE 通道约 ¥10（取决于你用的 IDE 套餐）；本地模型 ¥0。


### Q6：免费版够用吗？

够。免费版能完整写完一本书（限 1 项目 / 60 集 / 10 角色 / 10 模式 / 50 名词，AI 有月度额度），且 AI IDE 通道零成本不受额度限制。


### Q7：AI 报错看不懂（402 / timeout / 连不上）？

已自动翻译：所有 AI 错误都会变成人话卡片（余额不足 / 密钥错误 / 限流 / 超时 / 网络 / 内容风控…），并给出”下一步”按钮，还会折叠保留技术详情方便反馈。


### Q8：主角名总被判 block 怎么办？

规则引擎有一条”主角名必须在正文出现”。若你用了别名，去角色卡加上别名即可（白名单会带上别名）。


### Q9：伏笔总提示”应收未收”？

去「伏笔看板」把该伏笔的”应收集”改到实际位置，或在正文里补上回收。若确实想延后，可调整检查规则里的”伏笔兑现宽限集数”。


### Q10：换电脑了，数据怎么迁移？

设置中心 → 数据备份 → 导出 JSON；新电脑导入即可。建议定期导出，付费版可开自动云备份。


### Q11：误删了东西能恢复吗？

删除操作后有 5 秒撤销提示条，来得及就点撤销。超过窗口则用之前的 JSON 备份导入恢复（注意会覆盖全库）。


### Q12：为什么写作台有些 AI 按钮不见了？

你可能切到了「专注模式」——它会隐藏全部 AI 入口，只留正文全宽与底部守护灯。切回「轻松模式」即可恢复。


## 二、术语表


[表格]
术语 | 含义
40 维骨架 | 九大板块、40 个维度的世界观结构化模板，全书的地基
骨架评分 | 对 40 维逐维打分（0/1/2），换算百分制，分优秀/良好/及格/敷衍
阶段 / 卷 / 集 | Stage / Volume / Episode 三级大纲结构
情节点 | 一集内必须发生的事件；标”必须”的未覆盖会判 block
节奏标签 | 铺垫 / 蓄压 / 小爽点 / 大爽点 / 高潮 / 过渡，驱动模式卡推荐与节奏告警
模式卡 | 可复用的”爽点套路”，按节奏标签自动匹配注入
lorebook（设定词典） | 按正文命中自动抽取的名词解释，注入 AI 保证叫法统一
写前约束 | 生成前注入的 13 类硬约束（境界/金手指/关系/空间/伏笔/OOC…），让 AI 一开始就在骨架内写
规则引擎 | 11 条确定性校验，纯本地运行、零 Token
去 AI 味 | 词表 + 句式检测，给 flavorScore（0–100），越高越像 AI
守护灯 | 专注模式底部三盏灯（设定一致 / 伏笔 / 名词），静默守护、零 Token、不弹窗
文风避雷库 | 去味命中词累积库，下次写作自动规避；坚持保留的词会被弱化
回填 | 从正文自动抽取新设定（名词/角色/场景/伏笔/金手指/境界）并入库、绑定骨架
支线 / BOSS 阶梯 | 支线状态追踪与卷级反派威胁排序，断档会告警
实际进度账本 | 记录境界突破/金手指解锁”实际发生在哪一集”，优先于计划值
弹药（shelfRule） | 从别人书里拆解提炼出的可复用写法，注入写前约束
推演分支 | 剧情推演产出的不同走向，可采纳到分集或伏笔
三通道 | 本地模型 / AI IDE 文件交换 / 云端 API
block / warn / pass | 校验裁定：必须改 / 建议改 / 通过

[/表格]
