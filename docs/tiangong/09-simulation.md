# 09 · 剧情推演室
 卡剧情时怎么办：让角色 Agent 自己对话推演（L0 单轮 / L1 多轮+导演），分支对比并采纳回分集或伏笔。


这一篇讲什么：让角色”活”起来自己对话，看剧情往哪走；满意的走向可直接采纳成分集或伏笔。
前置条件：已有角色（见 04 篇）；推演需配置 AI 通道。
读完你能得到：几个可选的剧情走向，以及一条被采纳进正篇的分支。


## 一、它能干什么

推演室不是”让 AI 写一段”，而是给每个角色一个 Agent（带自己的目标、情绪、已知/未知、认知边界），让他们按人设对话，你看结果：


- L0 单轮：一次对话，看这一幕怎么发展

- L1 多轮 + 导演：连跑 1–5 轮，并可让”导演 Agent”做七维点评

- 张力曲线：看情绪起伏，峰值标红

- 分支保存：不同走向存成版本，对比后挑选

推演室：选角色 → 设轮数 → 跑推演 → 看张力曲线与分支


## 二、操作步骤


### 第 1 步：选模式与角色

顶部切「L0 · 单轮」或「L1 · 多轮 + 导演」；L1 可多选角色、设 1–5 轮，并勾选「导演 Agent 七维点评」。


### 第 2 步：编辑角色动态态（关键）

点角色卡编辑：目标 / 情绪 / 已知 / 未知 / 认知边界。


💡 这一步决定推演质量。比如反派”不知道”主角真实身份，两人才会演出错位感——信息差是戏剧张力的来源。


### 第 3 步：跑推演

点「▶ 跑 N 轮推演」。系统会：角色发言 → 谣言传播与感知更新 → 更新各自动态态 → 出张力曲线。


### 第 4 步：处理分支


[表格]
操作 | 作用
保存为分支 | 存成一个版本，可重命名、可打分（1–5 星）
采纳到分集 | 把这条走向写进某一集的大纲（真闭环）
采纳到伏笔 | 把推演出的悬念登记为伏笔
标记选定 | 在多个分支里标出”就这个”

[/表格]


### 第 5 步（可选）：角色采访

点「角色采访」直接问某个角色问题，用来验证人设是否立得住。


## 三、什么时候用它


[表格]
场景 | 怎么用
卡在”下一幕该发生什么” | 跑 L0，看角色自己会怎么反应
不确定反派动机说不说得通 | 编辑反派的”已知/未知”再跑，看是否自洽
两条走向选哪条 | L1 跑多轮存两个分支，对比张力曲线后挑选
想制造信息差 | 故意让 A 知道、B 不知道，看错位效果

[/表格]


## 四、本篇产物与下一步

做完这一篇，你得到：几条剧情走向、一条被采纳进正篇的分支（可选）。


常见卡点：


[表格]
现象 | 处理
跑不动 / 报错 | 推演不支持 AI IDE 通道，需配云端 API 或本地模型（见 11 篇）
角色说些不符合人设的话 | 补全角色动态态的”已知/未知/认知边界”，再跑

[/表格]
