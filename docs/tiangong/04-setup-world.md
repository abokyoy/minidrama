# 04 · 设定篇：骨架 · 世界 · 体系 · 金手指
 搭稳世界观：40 维骨架怎么填、角色/势力/空间怎么建、辅助体系与金手指怎么用，以及骨架评分怎么看。


这一篇讲什么：把”世界观”这件虚事落成可执行的数据——40 维骨架、角色、势力、空间、体系、金手指。
前置条件：已有一个项目（见 03 篇）。
读完你能得到：一个能支撑 AI 稳定写作的设定库。


## 一、40 维骨架（先填 3 个就能动笔）

进入「架构设定」→ 默认停在「骨架」页。


骨架页：九大板块、40 个维度，每维可单独编辑 / 评分 / 锁定


### 1.1 九大板块


[表格]
板块 | 管什么 | 新手优先级
基本信息 | 书名、类型、基调、平台 | 建项目时已填
故事内核 | 核心冲突、主题、卖点 | ⭐ 必填
阶段与主线 | 大阶段划分 | ⭐ 建议填
世界 | 地理、势力、社会 | 边写边补
人物 | 主角卡、配角、反派 | ⭐ 必填（主角）
体系 | 境界、功法 | 玄幻/仙侠必填
节奏 | 爽点分布 | 边写边补
伏笔 | 长线悬念 | 边写边补
收尾 | 结局方向 | 后期填

[/表格]


### 1.2 三个提效按钮


[表格]
按钮 | 作用
AI 引导生成 | 卡住的维度让 AI 先起一版（免费版每月有限次）
骨架评分 | 40 维逐维打分，给总健康分（优秀 ≥85 / 良好 ≥70 / 及格 ≥60 / 敷衍）
绑定数据 | 把某个维度绑定到具体角色/场景/势力，形成”维度 ↔ 实体”闭环

[/表格]


💡 骨架是活的：写作时系统会自动从正文抽取新设定（名词/角色/场景/伏笔/金手指/境界），你点确认即入库并自动绑定骨架维度（见 07 篇）。


## 二、角色

切到「角色」页，可新建角色并对角色做：角色卡、角色图谱、关系网。


角色页：角色卡 CRUD + 角色图谱（拖拽布局、拖拽建关系）

角色卡关键字段：


[表格]
字段 | 说明
角色定位 | 主角 / 女主 / 配角 / 导师 / 反派（主角名会被校验强制要求在正文出现）
所属势力 | 支持多势力（可跨空间）
别名 | 校验白名单会带上别名，避免误报
人设 / 目标 / 弧光 | 写前约束的来源，防 OOC

[/表格]


⚠️ 务必给主角设”定位=主角”：规则引擎有一条”主角名必须在正文出现”，主角没出现会判 block（必须改）。


## 三、势力

切到「势力」页：国家 / 家族 / 门派 / 组织，支持盟友、敌对、从属关系。


势力页：势力 CRUD + 势力图谱（盟友 / 敌对 / 从属）


## 四、空间（层级化世界观）

切到「空间」页，用父子层级组织地点：世界 → 大陆 → 国家 → 城 → 具体地点。


空间页：层级树 + 虚空版图（按层级显示地名）


💡 层级化的好处：写前约束能判断”角色此刻在不在这个空间”，越界会告警。


## 五、辅助体系（境界 / 功法 / 丹药…）

切到「体系」页，可自定义任意体系：


- 从模板库创建：内置 18 套预置（修炼境界、丹药、妖兽…），一键生成

- 自定义：定义层级（levels）、字段（schema）、多途径（tracks）、规则（rules）

- 一致性校验：检查层级名合法性、层级内聚

- @引用扫描：正文里写 @体系:条目 会被扫描登记

体系页：体系定义 + 条目 CRUD + 一致性校验


## 六、金手指

切到「金手指」页，登记主角的核心能力：系统 / 神器 / 体质 / 功法传承 / 血统 / 其他。


金手指页：能力卡 + 成长曲线 + 解锁集

关键：填「解锁集」，并在实际写到的那一集点「实际解锁」登记——写前约束会据此判断”这个能力现在能不能用”，防止主角提前开挂。


## 七、本篇产物与下一步

做完这一篇，你得到：填好的关键维度 + 角色 / 势力 / 空间 / 体系 / 金手指五类设定库 + 一个骨架评分。


常见卡点：


[表格]
现象 | 处理
40 维填不完 | 只填核心冲突、主角、金手指即可开写，其余靠自动回填
评分很低 | 看评分详情的”尚未填写”提示，优先补标红的维度
角色白名单误报 | 给角色加”别名”，或在名词库登记该叫法

[/表格]
