# 03 · 立项篇：新建与管理项目
 开一本新书：新建项目、填关键信息、导入外部项目、载入示例书、系列书与多项目管理。


这一篇讲什么：怎么开一本新书，以及怎么管理多本书（重命名、删除、导入导出、系列书）。
前置条件：软件已启动。
读完你能得到：一个可以开始搭骨架的项目。


## 一、新建项目

进入「项目启动」→ 点「新建项目」。


新建项目：书名 / 类型 / 基调 / 主题 / 平台 / 目标字数 / 目标集数

每栏怎么填：


[表格]
字段 | 说明 | 例子
书名 | 作品名，随时可改 | 《万界熔炉》
类型 | 玄幻 / 仙侠 / 都市 / 科幻… | 玄幻
基调 | 热血、压抑、轻松… | 热血
主题 | 一句话核心 | 少年从废柴到至尊
平台 | 起点 / 番茄 / 晋江…（影响上架节奏建议） | 起点
目标字数 / 集数 | 用于完本预测与进度条 | 300 万字 / 500 集

[/表格]


💡 填错没关系，后面都能改。目标字数与集数建议填一下——它是「完本预测」和进度条的计算基础。


产物：一个空项目，自动成为当前项目。


## 二、不想从零开始？三条捷径


[表格]
捷径 | 怎么做 | 适合
载入示例书 | 项目启动 →「载入《万界熔炉》示例书」 | 想先看饱满形态（3 阶段 / 9 卷 / 500 集全套数据）
一句话建书 | 进 Agent 首页（/agent），输入一句话 + 选题材爽点 | 想让 AI 反推 40 维骨架 + 七类设定
导入项目 JSON | 项目启动 →「导入项目」 | 从外部工具 / 别的电脑迁移

[/表格]


Agent 首页：一句话 + 题材爽点标签 → 反推 40 维骨架与七类设定

项目启动：项目列表 + 进度（骨架完成数 / 集数 / 角色数）


## 三、管理项目

在项目卡片上可以：


[表格]
操作 | 说明
重命名 | 直接改书名
删除 | 会级联清理该项目的草稿、校验报告、去味报告、检查点——有确认弹窗，删后 5 秒内可撤销
切换当前 | 侧栏底部项目栏切换；切项目后所有页面数据随之切换

[/表格]


⚠️ 删除不可恢复（5 秒撤销窗口过后）。重要稿件请先去「导出作品」做一次全库备份（见 11 篇）。


## 四、系列书与共享世界观

写系列作（同一世界观多本书）时用「系列书」：


- 项目启动 →「系列书」→ 新建系列

- 指定 世界观母本（哪一本书是设定源头）

- 把其它书加入系列，并可设阅读序号

- 写作时，母本的角色 / 场景 / 势力 / 名词只读共享；同名冲突会提示，可一键复制到本书

好处：续作不用重抄设定，且改了母本，续作能看到最新设定。


## 五、本篇产物与下一步

做完这一篇，你得到：一个当前项目（新建 / 导入 / 示例书三选一）。


常见卡点：


[表格]
现象 | 原因与处理
新建按钮灰掉 | 免费版限 1 个项目 → 删除旧项目或升级
导入失败 | JSON 格式不符 → 用「导出作品」导出的标准 JSON
载入示例书没反应 | 弹了确认框，需点「确定」；写入 500 集需等几秒

[/表格]
