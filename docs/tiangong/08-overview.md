# 08 · 总览篇：脉络 · 模式库 · 伏笔 · 名词
 从全局看一本书：全书脉络（2D/3D）、脉络规划驾驶舱、模式库、伏笔看板、名词库、健康度与模式效能。


这一篇讲什么：不写一章，而是看整本书——脉络怎么读、模式/伏笔/名词怎么管、健康度与效能怎么看。
前置条件：已有若干集与设定。
读完你能得到：一双”上帝视角”的眼睛，随时知道书的问题在哪。


## 一、全书脉络（BookMap）

三级俯视：L1 全景（阶段/卷泳道 + 里程碑 + 完成度）→ L2 阶段（叙事线 + 热力图）→ L3 单集特写。


全书脉络：缩放 / 平移 / 搜索 / MiniMap，点集可下钻

点「三维模式」可切到 3D——多轨泳道（伏笔 / 人物 / 主线 / 境界 / 金手指分层），可旋转、可按维度聚焦：


三维模式：把整本书变成一座可旋转的空中建筑


💡 空项目看不到东西？点页面上的「载入《万界熔炉》示例书」先看饱满形态。

## 三、四个资产管理看板

都在写作台底部「管理」菜单里，也可从全书脉络进入。


### 3.1 模式库（爽点方法论）

模式库：分类 / 强度 / 节奏标签 / 正例反例，可启停、导入导出

模式卡 = 可复用的”爽点套路”。写某集时，系统按节奏标签自动推荐并注入。


### 3.2 伏笔看板

伏笔看板：埋于第几集、应收于第几集、当前状态

状态：已埋（planted）/ 已收（paid）/ 超期（overdue）。到期未收会让守护灯的「伏笔」灯变黄。


### 3.3 名词库

名词库：分类 / 首现集 / 别名 / 触发词 / 注入方式

作用：统一叫法（玄天剑 vs 玄铁剑），并作为**设定词典（lorebook）**自动注入 AI。
