# 11 · 设置篇：AI 通道 · 授权 · 备份
 三种 AI 通道怎么选、各花多少钱、怎么配 Key；版本授权与激活；数据备份、恢复与迁移。


这一篇讲什么：配置问题全在这里——AI 通道、成本、授权激活、数据备份与迁移。
前置条件：无。卡在”AI 用不了”时直接看第一节。
读完你能得到：一条能跑通的 AI 通道，以及一份安全的备份。


## 一、三条 AI 通道怎么选

设置中心 →「AI 模型」页，三选一：


AI 模型页：三通道切换 + 厂商预设 + 可用性检测


[表格]
通道 | 怎么工作 | 成本 | 适合
AI IDE 文件交换 | 导出任务卡 → 粘进你熟悉的 AI IDE（Cursor / Claude Code 等）→ 回贴导入 | ¥0 | 不会配 Key、想用最强模型、要绝对省钱
云端 API 直连 | 填自家 Key，直连 DeepSeek / OpenAI / Kimi / 通义 / GLM 等 10 家预设 | ≈¥20 / 本（DeepSeek） | 图省事、要稳定质量
本地模型 | 连本机推理服务（LM Studio / Ollama 类，默认 localhost:5001） | ¥0 | 隐私优先、有显卡

[/表格]


💡 不配 Key 也能用：选「AI IDE 文件交换」即可，它不调模型、不烧 Token、免费版同样可用。


### 1.1 配云端 Key（以 DeepSeek 为例）


- 选「云端 API 直连」→ 厂商选 DeepSeek

- 填入 API Key（可勾”走 Worker 代理”隐藏 Key 并解决 CORS）

- 点「检测」→ 显示”可用”即成功

检查规则页：11 条规则开关 + 灵敏度滑块 + 守护灯开关


❌ 报错看不懂？错误已自动翻译成人话（余额不足 / 密钥错 / 限流 / 超时…），并给”下一步”按钮。


### 1.2 AI IDE 通道怎么用


- 通道切到「AI IDE 文件交换」

- 写作台点「导出任务卡」→ 得到一个 .md

- 把任务卡内容粘进你的 AI IDE，让它写正文

- 回来点「导入正文」，选保存好的 *_draft.md


⚠️ 该通道不支持流式生成，也不支持剧情推演（推演需真实模型）。


## 二、检查规则：调灵敏度

「检查规则」页可逐条开关 11 条确定性规则，并用滑块调灵敏度：


[表格]
可调项 | 含义
高频词判定阈值 | 出现几次才算”未登记名词”
错别字编辑距离容差 | 差几个字算疑似错字
伏笔兑现宽限集数 | 到期后宽限几集
情节点/金手指/境界/场景 覆盖比例 | 匹配度要求（严格/模糊）
爽点密度参考线 | 低于多少次/万字才提示

[/表格]


底部还有「写作台守护灯」开关——想要绝对安静可关掉。


## 三、版本与授权

「授权激活」页：


[表格]
版本 | 价格 | 关键差异
免费版 | ¥0 | 1 个项目 / 60 集 / 10 角色 / 10 模式 / 50 名词；AI 月度额度有限
专业版 | ¥199 / 年 | 全部不限 + EPUB 导出 + 自动云备份
永久版 | ¥399 一次 | 同上，买断

[/表格]


授权激活：设备码 + 激活码，支持全自动购买与离线码

激活方式：复制设备码 → 购买获得激活码 → 粘贴激活；或用内置「全自动购买」下单后自动轮询激活。离线环境可用离线升级码（ed25519 签名，无法伪造）。


💡 免费版够用吗：够。免费版能完整写完一本书（限 60 集），且 AI IDE 通道零成本。


## 四、数据备份与迁移

「数据备份」页，或去「导出作品」：


数据备份：导出 / 导入 JSON；付费版可开自动云备份


[表格]
操作 | 怎么做 | 什么时候
导出全库 JSON | 设置 → 数据备份 → 导出 | 换电脑前、大改前
导入恢复 | 设置 → 数据备份 → 导入（需手输”删除”二次确认） | 换电脑、误删后
自动云备份 | 付费版：日/周 → 腾讯云 COS / 阿里云 OSS | 长期防丢
导出成书 | 导出作品 → Markdown / EPUB | 完本或发布

[/表格]


进入「导出作品」可导出全书：


导出中心：全书 Markdown / EPUB + 全库 JSON 备份 / 恢复


[表格]
导出项 | 说明
全书 Markdown | 单文件 md，方便发任何平台
EPUB | 自研打包，可直接导入阅读器（付费版）
运营层模板 | 可勾选”章节 CTA / 作家的话 / 上架感言”，只在导出时拼接，不改动你的原稿

[/表格]


⚠️ 导入恢复会覆盖全库，所以必须手输”删除”才能执行——这是防误操作的最后一道闸。


## 五、本篇产物与下一步

做完这一篇，你得到：一条可用的 AI 通道 + 一份全库备份。


常见卡点：


[表格]
现象 | 处理
检测一直”不可用” | 检查 Key、网络、代理地址；或改走 AI IDE 通道
提示额度用完 | 换 AI IDE 通道（零成本），或等次月重置 / 升级
换电脑数据没了 | 用之前导出的 JSON 在新电脑导入

[/表格]
