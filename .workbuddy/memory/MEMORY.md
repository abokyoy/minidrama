## 3 提示词·机位·参考图（头号根因=超长）
- 正文**350–580英文词**；超长=动作稀释=全糊。⭐打斗/追逐前**先读官方示例原文**（Category 3 Rooftop Chase，10秒6刀，音效到毫秒），不要只读规范自己写。
- 否定句可用但须正确：正面描述为主+结尾1–2句针对本镜真实风险的可观测否定（`No slow-motion, wire rigs, duplicated swords, distorted limbs`）；⛔禁代替正面描述、禁泛用`no bad quality`。
- 机位定版：**6刀硬切**全`Camera: Static Shot, locked off`（切点0/1.25/2.5/3.75/5/6.5s），同侧机位锁位。⛔禁Whip Pan/Tracking/Arc；⛔连两刀Push In→脸糊；密度靠每刀加可观测细节。
- 参考图=单人正面全身（设计图含4视角→裁单张）；人物复制第一因=参考图给多/服装描述多；排查顺序①图里有几人②画面人物有无对应图③几张环境图④有无否定句（查完①其余免查）。
- 工具会骗人：换参考图读的是input旧图（文件名带md5+定位实例自己input）；花屏查**码率**(正常4.0M/花屏10.4M)；检测器抓不到侧脸背身→**必须抽帧拼图人眼看**；**日志打印路径不可信→用`ls -lat`核对真实落盘**；中间产物固定名须每次重算；校验器本身会骗人→上线前造已知答案样本自验。

## 4 续写链·字段·生成器纪律
- 续写链：奇段fixed，偶/下一段chain接上一段，每满3段断链重启ComfyUI（避免越接越黑）。⛔chain第1段绝对不能用（节点写死他人路径→prev=None必用fixed）。⛔参考图数量须与已认可段逐字一致。⛔**禁正则批量改写镜头段**（截断句子→相邻两刀重绘同脸越推越虚），要改用Edit精确改每刀+抽帧人眼核对。
- 字段：`lean_shots`才是渲染器实际读的（非`_lean_shots`）；改lean档须同步`lean_shots/shots/_lean_shots`。「只走覆盖层+sha零影响」铁律**已作废**（用户确认）→真正需拍sha的是4个模块级常量+render两行。
- 生成器：每次生成前`reclaim_before_gen()`清场（杀gh.exe等占内存进程）；**一次完整生成13–15分钟**；两实例不能同时跑；所有脚本开头**pop proxy环境变量**再硬编码`127.0.0.1:10808`；常用命令见原稿§8（`_h3_audit.py`/`check_beats.py`/`_ai_taste.py`/`_dup_check.py`等）。
