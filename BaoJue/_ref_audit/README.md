# 参考图检查清单（xs001 第一集实际送进模型的全部图）

## 你要看什么

请重点看**每张图人物的上半身正面**，胸口位置有没有：
- 挂牌子 / 工牌 / 胸卡（矩形卡片，尤其带色带或挂绳）
- 挂绳（脖子上挂下来的带子）
- 别针 / 夹子 / 卡 holder
- **任何文字**（包括衣服上的字、图案、logo）
- 围裙的**肩带在胸前交叉**（交叉点就是一个空隙，模型会往那儿挂东西）

## 我已经发现的（供你参考，不用只信我）

1. **苏小满的围裙是「交叉背带」** —— 两条带子在胸前交叉成一个 V 字空隙，
   这个空隙就是模型挂工牌的位置。这张参考图本身没有工牌，但**结构上留了空位**。
2. **钱经理那张很干净** —— 白衬衫扣到领口+ 深灰马甲扣满，胸前只有 V 领口一小块，
   没有任何挂东西的结构。
3. 我之前只重画了**苏小满、钱经理**两张。小唐、阿芳、以及旧集里其他角色
   （前台、医生、收费员、周总监…）**没有全部复查过**。
