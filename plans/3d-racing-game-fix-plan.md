# 3D赛车游戏问题修复计划

## 问题分析

**症状**：点击开始游戏后，页面全是黑色，只有一个红色方块（车辆），看不到赛道。

**根因诊断**：
1. **赛道绘制逻辑错误**：`drawTrack()` 函数中，赛道点的计算方式是将玩家坐标从世界空间转换到摄像机空间，然后直接绘制线。但赛道点是按固定顺序生成的，没有考虑玩家的旋转方向，导致赛道不在视野内。
2. **赛道太短**：只生成 500 个赛道点，且没有考虑玩家移动后赛道应该动态跟随。
3. **赛道宽度计算有误**：赛道边缘线计算使用 `40 - i * 0.2`，但 `i` 是相对于玩家当前位置的偏移，导致赛道宽度在玩家移动后很快变负。

## 实现计划

### Phase 1：修复赛道渲染逻辑（中）

**目标**：确保赛道在玩家视野中正确显示，支持玩家移动。

**方案**：
1. 将赛道生成改为**无限赛道**：赛道点随玩家移动动态生成，确保玩家永远在赛道上。
2. 使用**正交投影**简化赛道绘制：以玩家视角为中心，将赛道点投影到屏幕空间。
3. 修复赛道宽度计算，确保边缘线正确显示。

**具体实现**：
- 生成赛道点时，使用 `player.distance % track.totalLength` 作为偏移量
- 赛道点计算使用玩家当前的 `player.angle` 作为参考方向
- 赛道宽度保持固定值，不随距离变化

### Phase 2：增强赛道视觉效果（低）

**目标**：让赛道看起来更真实，有弯道和直道变化。

**方案**：
1. 增加赛道的弯道效果：在赛道生成时加入正弦函数模拟弯道。
2. 增加赛道纹理：使用不同颜色表示赛道边缘和中心线。
3. 增加赛道标志：在赛道上加入距离标记和弯道提示。

**具体实现**：
- 赛道生成时加入弯道参数：`const curve = Math.sin(i * 0.05) * 0.1`
- 赛道颜色根据弯道程度变化
- 加入距离标记（每1000米标记一次）

### Phase 3：增加更多视觉元素（低）

**目标**：让游戏场景更丰富，增加视觉吸引力。

**方案**：
1. 增加路标：在赛道旁加入距离标记和弯道提示。
2. 增加路边元素：加入树木、路灯等场景元素。
3. 增加天空效果：加入星空或云层背景。

**具体实现**：
- 在赛道旁加入树木渲染
- 加入天空渐变背景
- 加入星空效果

### Phase 4：测试和验证（低）

**目标**：确保所有功能正常工作，无视觉bug。

**方案**：
1. 测试赛道渲染是否正确。
2. 测试玩家控制是否流畅。
3. 测试不同速度下赛道渲染是否正常。
4. 测试弯道视觉效果是否正确。

## 技术细节

### 赛道渲染公式

```javascript
// 赛道点的世界坐标
const worldX = trackPoint.x - player.x * Math.cos(player.angle);
const worldY = trackPoint.y - player.y * Math.sin(player.angle);

// 转换为屏幕坐标
const screenX = worldX * scale + canvas.width / 2;
const screenY = worldY * scale + canvas.height / 2;
```

### 赛道点生成

```javascript
// 生成无限赛道点
function generateTrackPoint(index) {
    const curve = Math.sin(index * 0.05) * 0.1;
    const x = index * 10 + Math.sin(index * 0.1) * 100;
    const y = Math.cos(index * 0.1) * 50;
    return { x, y };
}
```
